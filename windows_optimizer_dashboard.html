🧹 Limpeza Segura

Use o ícone "Limpar Sistema - Prévia" na Área de Trabalho. Se ainda não instalou os ícones, rode primeiro INSTALAR_ATALHOS.bat.

python system_cleaner_advanced.py
  • Mostra prévia do que será deletado
  • Cria restore point automaticamente
  • NADA é deletado nesta primeira execução

Para aplicar de verdade, use o ícone "Limpar Sistema - Aplicar":

python system_cleaner_advanced.py --apply

🔧 Reparar Mousepad

Método mais fácil:

Ícone "Reparar Touchpad" (Recomendado)

  • Rode INSTALAR_ATALHOS.bat uma vez (se ainda não fez)
  • Clique duas vezes no ícone "Reparar Touchpad" na Área de Trabalho
  • Ele pede admin sozinho — clique em "Sim"
  • Aguarde a reinicialização (30 segundos)

Alternativa manual: Clique Direito

fix_touchpad.bat

⚙️ Customizar Configuração

Edite o arquivo de configuração:

notepad cleaner_config.json

O que você pode customizar:

  • Habilitar/desabilitar categorias
  • Mudar localizações de scan
  • Ajustar padrões de arquivo
  • Configurar comportamento de segurança
  • Ativar/desativar dry-run

Depois de editar, use o ícone "Limpar Sistema - Prévia" de novo para conferir.
