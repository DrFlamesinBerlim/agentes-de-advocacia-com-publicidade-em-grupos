# Contribuindo para Dra. Julia - Agente IA Advocacia

Obrigado por considerar contribuir para este projeto!

## Como Contribuir

### Reportando Bugs
1. Verifique se o bug já foi reportado nas Issues
2. Crie uma nova issue usando o template de bug report
3. Inclua o máximo de detalhes possível

### Sugerindo Melhorias
1. Verifique as issues existentes para evitar duplicatas
2. Crie uma nova issue usando o template de feature request

### Contribuindo com Código
1. Faça um fork do projeto
2. Crie uma branch para sua feature
3. Commit suas mudanças
4. Abra um Pull Request
