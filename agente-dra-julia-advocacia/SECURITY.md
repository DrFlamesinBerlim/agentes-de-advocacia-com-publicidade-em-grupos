# Security Policy

## Relatando uma Vulnerabilidade

NÃO crie uma issue pública. Envie email para: opta.labs.ia@gmail.com

Inclua: descrição da vulnerabilidade, passos para reproduzir, impacto potencial, versão afetada.

Tempo de resposta: confirmação em 24-48h, avaliação em 5-7 dias úteis.

## Diretrizes
- Tokens e API Keys: sempre use variáveis de ambiente
- Webhooks: implemente verificação de tokens
- Use HTTPS para todas as comunicações
- Siga LGPD e boas práticas OWASP
