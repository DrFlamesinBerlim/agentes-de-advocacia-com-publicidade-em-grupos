# 🏛️ DRA. JÚLIA - AGENTE IA ADVOCACIA ⚖️

**Agente de IA jurídica completo com automação N8N para WhatsApp Business**

v2.0 — Segurança OWASP · 35 nós · 9 áreas jurídicas · Graph API v20.0

## Instalação Rápida

1. Clone: `git clone https://github.com/JeffersonMFti/agente-dra-julia-advocacia.git`
2. Importe `workflows/dra-julia-agente-ia-advocacia.json` no N8N
3. Configure variáveis de ambiente: OPENAI_API_KEY, WHATSAPP_TOKEN, PHONE_NUMBER_ID, WHATSAPP_VERIFY_TOKEN, GOOGLE_SHEETS_ID

Ver documentacao/GUIA-INSTALACAO.md para detalhes completos.
